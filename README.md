# 三人经典斗地主 · Python 版 1.1

作者：**Tonny陳**。独立桌面小游戏，真人对战“电脑1”（右侧）与“电脑2”（左侧）；安装依赖后离线游玩。交付内容为完整 Python 源码，没有 exe。

本次更新：精简首页，只保留大标题、装饰牌和必要操作；底部显示作者及当前实际运行的 Python 版本；新增选牌与按钮两种短音效，右上角可以开关。音效由程序生成，没有背景音乐，不需要额外下载素材或安装新依赖。

**已运行过上一版：**退出旧游戏，将本包完整解压，进入新文件夹运行 `python main.py` 即可。不要只替换 `app.py`，本版增加了 `sound.py`。现有 Python 环境和依赖可继续使用。

## 从零运行（Windows）

1. 安装 **Python 3.10 或更高版本**。本次测试使用 Python 3.12；安装时勾选 **Add python.exe to PATH**。
2. 将整个源码包解压到一个普通文件夹，例如桌面的“三人经典斗地主”。**不要只复制 main.py，也不要在压缩包里直接运行。**
3. 在解压后的文件夹中打开终端：文件资源管理器地址栏输入 `powershell`，回车。
4. 首次运行前安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

5. 启动游戏：

   ```powershell
   python main.py
   ```

以后只需第 5 步。如果你的电脑用 `py` 启动 Python，将上面的 `python` 换成 `py` 即可。保持终端打开，可以看到启动错误。

唯一第三方依赖为 **pygame-ce 2.5.8**，代码中的导入名仍为 `pygame`。[pygame-ce 官方安装说明](https://github.com/pygame-community/pygame-ce#installation)。不需要单独安装 `pygame`；如果旧环境已经装过它，建议新建虚拟环境后安装本项目依赖：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe main.py
```

## 怎么玩

1. 首页选择新手、普通或困难，点击“开始新的一局”。
2. 按提示叫地主、抢地主，等待电脑行动；地主获得底牌并先出。
3. 点击手牌选中，牌会上浮；再次点击取消。可以提前选牌。
4. 点击“出牌”确认；“提示”只替你选牌，不会直接打出，连续点击可以换一组。
5. 一家出完后结算。按空格重新开始同难度；点击“更换难度”回到首页。

| 操作 | 鼠标 / 快捷键 |
| --- | --- |
| 选牌、取消选牌 | 左键点击手牌 |
| 出牌 | 出牌按钮 / Enter |
| 不出 | 不出按钮 / P；本轮首出不能不出 |
| 提示、下一组提示 | 提示按钮 / H |
| 清空选牌 | 清空选牌按钮 / 鼠标右键 |
| 查看规则 | 右上角“规则” |
| 暂停、返回菜单 | 右上角“菜单” / Esc |
| 继续当前局 | 首页“继续当前对局” / Esc |
| 结算后重新开始 | 再来一局 / 空格 |
| 开关点击音效 | 首页或牌桌右上角“音效：开 / 关” |

窗口可拖动边缘调整大小，画面等比缩放，比例不同时保留边缘留白。推荐窗口至少 1000×625，以便看清中文与牌面。进入菜单或规则页面时，电脑暂不执行下一步。关闭窗口即退出，不保存未完成对局。

## 本版规则

无癞子，54 张牌。每家 17 张，3 张底牌；顺序为 **你（下）→ 右家 → 左家**，地主先出。上方“回合”在连续两家不出、重新领出时增加。

### 叫抢

- 随机首叫者；有人叫地主后进入抢地主。三家都不叫则重新发牌。
- 首叫者之后的两家各抢一次，包括此前选择过“不叫”的席位。
- 若有人抢过，首叫者有最后一次抢地主机会；最后抢者成为地主。
- 初始 1 倍，叫地主不翻倍，每次抢地主 ×2；确定地主后才公开 3 张底牌。

### 牌型

| 牌型 | 条件 / 示例 |
| --- | --- |
| 单张、对子、三张 | 3；44；555 |
| 三带一、三带二 | 777A；777AA |
| 顺子 | 至少 5 张，34567 |
| 连对 | 至少 3 对，334455 |
| 飞机 | 至少两组连续三张，333444 |
| 飞机带单 | 每组带一张，33344467；也允许 33344466 |
| 飞机带对 | 每组带一对不同点数的对子，3334446677 |
| 四带二单 | 四张带两张，888834 或 888833 |
| 四带两对 | 四张带两个不同点数对子，88883344 |
| 炸弹 | 四张同点数，KKKK |
| 王炸 | 小王与大王 |

点数：3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王。花色不比较大小。

顺子、连对和飞机主体均不能含 2 或王。飞机带牌不能与主体同点，单翅每个点数最多两张；飞机单翅和四带二单不能同时携带大小王。对子翅必须点数不同，不能将一个炸弹视为两对。**四带二不是炸弹，不翻倍。**

跟牌要求牌型、张数一致且主体更大，带牌大小不比较。炸弹压所有普通牌，更大的炸弹压小炸弹，王炸最大。主动不出是允许的；首出必须出牌。两家连续不出后，最后成功出牌者重新领出。

### 胜负与倍数

地主出完则地主胜；任一农民出完则两位农民共同胜利。炸弹、王炸各 ×2。地主胜且两位农民都未出过牌为春天 ×2；农民胜且地主仅成功出过一手为反春天 ×2。

结算以 1 分为基础：地主得失为最终倍数的 2 倍，每位农民得失为最终倍数的 1 倍，三方合计为 0。分数仅展示本局，不累计、不涉及支付。

## 三档电脑

- **新手**：会错过能压过的牌，会随机拆牌，不特意保炸弹、不做残局搜索。
- **普通**：记录公开出牌，整理连续牌和三张，减少拆炸弹；考虑队友和报单拦截。
- **困难**：更重视剩余大牌、阻拦敌方与保留炸弹；小手牌做出完手数估计；全桌剩余不超过 12 张时，对最多 6 个出牌候选和“不出”做最多 6 次未知牌抽样搜索。

电脑只接收自己的手牌、公开出牌、底牌和各家剩余张数，不会读取其他玩家的隐藏手牌。困难档的搜索有节点和时间预算，所以它更谨慎，但不是每个残局都能算到必胜。AI 和提示在后台计算，主窗口持续响应。提示使用独立的候选排序，不会改变洗牌随机数。

## 中文与故障排查

- Windows 自动使用系统“微软雅黑”。
- `No module named pygame`：在运行游戏的同一个 Python 环境执行安装依赖命令。
- 提示找不到中文字体：在项目内创建 `assets` 文件夹，放入合法可用的中文字体并命名为 `font.ttf`，或设置 `DDZ_FONT` 为字体完整路径。macOS / Linux 会尝试苹方、Noto Sans CJK 等字体，未在这些系统做实机测试。
- 启动报错或电脑异常：查看 `main.py` 同目录的 **三人经典斗地主.log**。若异常发生在依赖安装阶段，请保留终端的错误文字。
- 文字偏小：放大窗口。窗口默认 1280×800，按 1440×900 逻辑画布绘制，不会只显示在右上角。
- 没有声音：确认右上角显示“音效：开”，检查系统音量和 Python 应用音量。若显示“音效不可用”，说明音频设备初始化失败，游戏仍可静音运行，详情见日志。关闭音效后本次运行持续静音，重启默认开启。
